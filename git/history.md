Git was created in **2005** by **Linus Torvalds**, the same person who created Linux. Here’s a quick history:

1. **Before Git** – Developers used older systems like **CVS** and **Subversion (SVN)**, which were slow and required constant internet access.

2. **Why Git?** – The Linux kernel team needed a **fast, distributed** version control system after a licensing dispute with BitKeeper (their previous tool).

3. **Git is Born** – Linus built Git in just **10 days**! It was:

   - **Distributed** (everyone has a full copy of the project).
   - **Fast & Efficient** (handles large projects like Linux).
   - **Open Source** (free for everyone).

4. **GitHub (2008)** – A platform for hosting Git projects made Git even more popular.

Today, Git is the **#1 version control system** used by developers worldwide. 🚀
